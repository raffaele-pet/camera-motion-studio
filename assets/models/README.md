# Fox sample model

`Fox.glb` is bundled unchanged from the [Khronos glTF Sample Assets Fox model](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox). It includes the Survey, Walk and Run animation cycles and loads by default in Camera Motion Studio.

Credits from the [upstream metadata](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/main/Models/Fox/metadata.json):

- Model: **PixelMannen** (2014), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/legalcode).
- Rigging and animation: **tomkranis** (2014), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode).
- Conversion to glTF: **@AsoboStudio and @scurest** (2017), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode).

The upstream license notice is included in [LICENSE-Fox.md](LICENSE-Fox.md). The original geometry, textures and animations have not been modified; the editor fits the model to its preview at runtime.
